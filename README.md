# Null Detailing Website

## Live Website

Visit [nulldetailing.com](https://nulldetailing.com/).

This is the front-end codebase for [Null Detailing](https://nulldetailing.com), a mobile car detailing service in St. Charles and St. Louis Counties. 

The application is built using React and Vite. It is designed to be a fast, responsive single-page application with modern styling and performance optimizations.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Included Features
- Integrated Booking Form (via iframe)
- SEO Meta Tags (Open Graph, Twitter) targeting local service areas
- Dark/Light Theme Support
- CSS Grid & Flexbox Layouts for mobile responsiveness 

## Deployment Setup
This project is configured for deployment on **Vercel** with a `vercel.json` file providing standard security headers.
